## 📂 1. Bulk Data Ingestion Engine (Spreadsheet Parser)
* **The Import Terminal Flow:** Drag-and-drop workspace window for `.xlsx` spreadsheets with template downloads (`Download_Student_Template.xlsx` and `Download_Timetable_Template.xlsx`).
* **Roster Import Guard:** Format verification, duplicate roll number abort check, phone number E.164 verification.
* **Timetable Scheduler Guard:** Relational teacher UUID mapping, class overlap detection, teacher overlap check, and conflict highlighting.

## 📉 2. Syllabus Completion Tracking Module
* **Dual-Lens Filtering Interface:**
  * **"By Teacher" View:** Evaluates individual teacher velocity across all assigned grades.
  * **"By Class" View:** Class-by-class matrix layout highlighting lagging subjects (e.g. Science 20% 🚨 DELAY).

## 📊 3. Subject-Wise Class Analytical Reports
* **Live Average Score:** Mathematical mean ($\mu$) calculated in real-time.
* **Grade Score Spread:** Visual tiers (A Grade, B Grade, Failing $<40\%$).
* **Historical Timeline Graphs:** Timeline trendline plotting test progress across Quiz 1, Quiz 2, Quiz 3, and Finals.

## 🎛️ 4. Direct Micro-Correction Data Grid
* **In-Line Editing:** Click cell to edit student names, roll numbers, or room assignments with live sync to teacher devices.

## 👤 5. Teacher System Impersonation (Audit Tool)
* **Interactive Smartphone Wireframe Viewer:** Embedded mobile frame on the desktop canvas simulating the exact live view of any selected teacher.

## 📥 6. Executive Progress Report PDF Compiler
* **Document Assembly Engine:** Compiles official audit with administrative header, attendance discipline %, academic grade grid, critical risk alerts, and curriculum checklist.

## 💬 7. Relationship Management System (RMS) Inbox
* **Priority Inbox:** Direct tray for leave requests, gear/lab repairs, and confidential alerts with Approve/Resolve actions.
